# Module 6 Lab: Teen Hangout

A C# Razor Pages application with three members and three posts. The page displays all members, all posts, and posts with 20 or more likes using arrays, loops, and a conditional.

## Run in GitHub Codespaces

1. Click **Code**, then **Codespaces**. Open a codespace or create one on **main**.
2. In the terminal, run:

   ```sh
   cd TeenHangout
   dotnet run
   ```

3. Open the forwarded port **5088** in the browser.
4. Press **Ctrl+C** in the terminal when finished.

The codespace configuration includes .NET 8 and the C# Dev Kit. To run locally, install the .NET 8 SDK and use the same commands.
